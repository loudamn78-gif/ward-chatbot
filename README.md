# 🌸 مشروع شات بوت متجر ورد (Ward Chatbot)

شات بوت تفاعلي تم تطويره بلغة **Python** لتقديم تجربة دعم عملاء آلية ومباشرة لمتجر "ورد". يساعد البوت العملاء في الاستفسار عن المنتجات، أنواع الورد، العطور، الأسعار، وخيارات التوصيل المتاحة.

---

## 📑 تفاصيل ومميزات المشروع
- **الردود الذكية والإرشادات:** يتعرف البوت على الكلمات المفتاحية في أسئلة العميل ويقدم إجابات فورية ودقيقة.
- **معالجة اللغة العربية:** دعم كامل للغة العربية وإصلاح مشاكل التنسيق والحروف المنفصلة في واجهة السطر البرمجي.
- **القائمة التفاعلية:** توفير خيارات واضحة للمستخدم للاستفسار عن العطور، الورد، الأسعار، أو التوصيل.
- **المرونة والاحتياط:** التعامل مع المدخلات غير المفهومة وتوجيه المستخدم لإعادة السؤال بطريقة صحيحة.

---

## 🛠️ دالة إصلاح النص العربي (Arabic Text Processing)

عند استخدام النصوص العربية في بعض بيئات التشغيل والرسوم البيانية، قد تظهر الحروف العربية معكوسة أو منفصلة. تم حل هذه المشكلة برمجياً عبر دالة مخصصة تقوم بربط الحروف وتعديل اتجاه النص من اليمين إلى اليسار:

```python
from arabic_reshaper import reshape
from bidi.algorithm import get_display

def fix_text(text):
    """
    دالة لمعالجة النصوص العربية وإصلاح طريقة عرضها:
    1. إعادة تشكيل الحروف وربطها ببعضها (reshaping).
    2. تعديل اتجاه النص من اليمين إلى اليسار (BiDi algorithm).
    """
    reshaped_text = reshape(text)
    bidi_text = get_display(reshaped_text)
    return bidi_text
